| 维度          | unsafe.Pointer                                      | uintptr          |
| ----------- | --------------------------------------------------- | ---------------- |
| 本质          | 特殊指针类型                                              | 无符号整型（足够存地址）     |
| 能否解引用       | ✅ 可直接 `*p` 访问对象                                     | ❌ 纯数字，解引用会编译错误   |
| 能否参与 GC 根扫描 | ✅ GC 把它当活指针                                         | ❌ GC 无视，对象可能被回收  |
| 能否做指针运算     | ❌ 不允许 ± 运算                                          | ✅ 可随意 `+ - & \|` |
| 类型安全性       | 保留原始类型信息                                            | 完全丢失类型           |
| 典型用途        | 跨类型转换桥梁                                             | 计算偏移、手写内存布局、汇编交互 |
| 转换关系        | `Pointer ↔ uintptr` 双向允许，但**必须在同一表达式内完成**（防止 GC 移动） |                  |

错误示例：
u := uintptr(ptr)   // 先存变量
ptr = unsafe.Pointer(u) // 对象可能已被 GC 移动！
正确示例：
ptr = unsafe.Pointer(uintptr(ptr) + offset) // 一步完成

| 维度   | 内存逃逸（Escape Analysis）            | 内存溢出（OOM/Out of Memory）                                              |
| ---- | -------------------------------- | -------------------------------------------------------------------- |
| 触发者  | 编译器（静态分析）                        | 运行时（申请不到内存）                                                          |
| 结果   | 变量从栈→堆，GC 负担↑                    | 进程被 OS/虚拟机 Kill，或抛 OOM 异常                                            |
| 是否可用 | 仍可用，只是慢                          | 不可用，程序崩溃                                                             |
| 报错   | 无报错，只能 `go build -gcflags=-m` 查看 | `fatal error: runtime: out of memory` / `java.lang.OutOfMemoryError` |
| 解决思路 | 减少对外暴露、内联、值类型                    | 减少内存占用、扩容、限流、分页、缓存淘汰                                                 |

| ---- | ------------ | --------------- | ----------------------- |
| 所属空间 | 内核态          | 内核态             | 用户态（运行时调度）              |
| 地址空间 | 独立           | 与进程共享           | 与线程共享                   |
| 创建开销 | ≈ 百 KB~MB    | ≈ 几十 KB         | ≈ 2 KB（Go）              |
| 调度器  | 内核 CFS       | 内核 CFS          | Go M∶P∶G 模型（用户态）        |
| 切换代价 | 页表+TLB，µs~ms | 内核栈+寄存器，百 ns~µs | 只换寄存器，< 20 ns           |
| 并发量级 | 单机几千         | 单机 1~10 万       | 单机百万级                   |

| 崩溃影响 | 互相隔离         | 任意线程崩→整个进程死     | 一个 panic 可 recover，进程仍在 |
| 并行度  | 多核/多机        | 多核              | 多核（M 绑定 P）              |
